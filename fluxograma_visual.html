📌 Explicação do Fluxograma Principal:
O processo começa com a coleta de dados de múltiplas fontes (satélites, sensores, drones). Esses dados são processados em tempo real e analisados por algoritmos de IA. Os resultados são divididos em 5 áreas de atuação, gerando alertas e insights que guiam a ação humana para preservação efetiva. Um sistema de feedback contínuo melhora constantemente os algoritmos.

🎯 Árvore de Decisão: Quando IA detecta um problema, segue uma árvore de decisão que avalia urgência, escala e tipo de intervenção necessária. Problemas críticos (desmatamento, caça ilegal) acionam respostas imediatas com coordenadas precisas. Problemas menos urgentes são monitorados continuamente. Cada caminho leva a ações específicas com equipes apropriadas.

📚 Legenda Técnica e Abreviações

CNN: Redes Neurais Convolucionais para processar imagens
LSTM: Long Short-Term Memory para séries temporais
GRU: Gated Recurrent Unit para previsões
YOLO: Real-time object detection para visão
ResNets: Deep Residual Networks para visão computacional
ETL: Extract, Transform, Load de dados
IoT: Internet of Things - sensores conectados
AQI: Air Quality Index - índice de qualidade do ar
IA: Inteligência Artificial
ML: Machine Learning
